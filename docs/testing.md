# 안전망 테스트

리팩토링 중에 **사용자가 보는 화면과 계산 숫자가 바뀌지 않았는지** 확인하는 테스트다.
실제 크롬(Playwright)으로 앱을 열어 사용자처럼 누르고, 결과를 저장해 둔 스냅샷과 비교한다.

## 돌리는 법

```bash
npm install                        # 처음 한 번
npx playwright install chromium    # 처음 한 번
npm test                           # 테스트 실행
```

## 무엇을 확인하나

| 파일 | 따라가는 길 | 비교하는 것 |
|---|---|---|
| `tests/demo.spec.mjs` | 앱 열기 → 예시 먼저 보기 → 달마다 · 1년 · 예상 잔액 그래프 | 예시 거래 2,363건의 계산 숫자 전부, 화면 글자 |
| `tests/upload.spec.mjs` | 은행 엑셀 올리기 → 매장 이름 → 대표자 → 거래처 20곳 분류 → 목표일 → 결과 → 새로고침 → 이어서 보기 | 단계마다 화면 글자, 계산 숫자, 브라우저 저장 자료, **되살린 숫자 = 저장 전 숫자** |

- 시계는 `2026-09-23 10:00 (서울)`로 고정한다. 앱이 오늘 날짜를 쓰는 곳이 있어서다.
- 은행 엑셀은 예시 거래로 만든 대역이다. 실제 은행 파일은 저장소에 넣지 않는다.

## 테스트가 실패하면

1. `test-results/` 안의 `*-actual.*` 와 `tests/snapshots/` 의 원본을 비교한다 (`diff`).
2. **리팩토링 PR** 이면 → 코드가 잘못된 것이다. 코드를 고친다.
3. **일부러 화면이나 계산을 바꾼 PR** 이면 → 바뀐 내용이 의도대로인지 확인한 뒤 스냅샷을 새로 찍는다.

```bash
npm run test:update
```

스냅샷을 새로 찍은 PR 에는 **무엇이 왜 바뀌었는지** 적는다.
