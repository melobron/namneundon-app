# 124차 — 결과 화면 AI 질문 시험

2026-10-16 사용자의 직접 구현 요청으로 작성했다. 별도 프로젝트 설계 문서는 직접 열람하지 않았으며,
이번 요청에 붙인 명세와 대화에서 확정한 범위를 근거로 했다. 앱은 정적 파일 그대로이며 `chat/`만 별도 Worker다.
push·PR·병합·배포·wrangler 실행·D1 생성은 이 작업에 포함하지 않는다.

## 경계와 저장

- 기본 숨김. 국외 이전 조건 확인 전에는 **합성 자료 시험자만** 쓴다.
  - 앱: `?aikey=<키>`로 들어오면 키를 이 브라우저(`fc.ai.tester`)에 저장하고 표시를 켠 뒤 `history.replaceState`로 주소창에서 키를 바로 지운다.
    키가 없으면 진입 아이콘을 그리지 않는다. `?ai=1`만으로는 켜지지 않는다. `?ai=0`은 표시와 키를 함께 지운다.
  - 서버: `POST /api/chat`·`DELETE /api/chat/*`는 헤더 `X-Namneundon-Tester`가 비밀값 `TESTER_KEY`와 같을 때만 처리한다.
    없거나 다르면 본문을 읽기 전에 403 — AI 호출·사용량 기록·저장 없음. 두 값을 SHA-256 해시로 바꿔 끝까지 비교한다(상수 시간).
    `TESTER_KEY`가 설정되지 않았으면 모든 질문·삭제가 403이다.
  - 키는 요청 헤더로만 보낸다. 전송 요약·화면·로그·스크린샷에 넣지 않는다.
    키는 **영문 소문자·숫자만**(1~256자) 쓴다(예: `openssl rand -hex 32`). 앱은 다른 형식을 저장·표시하지 않고, 서버는 형식이 다른 비밀값·헤더를 403으로 막는다.
- 진입점은 **결과 화면 오른쪽 아래 동그란 아이콘** 하나다. 앱에 있는 남는돈 마크(`BRAND_MARK`) + 작은 「AI」 표시, 접근성 이름 「AI에게 결과 묻기」.
  휴대폰(520px 이하) 48px, PC 56px. 화면 끝에서 16px + 안전 영역(`env(safe-area-inset-*)`). 다른 화면에서는 결과와 함께 감춰진다.
  - 아이콘이 결과를 가리지 않도록 결과 화면 맨 아래에 아이콘 높이 + 여백만큼(휴대폰 80px, PC 88px + 안전 영역) 비운다.
    결과 영역 높이는 제한하지 않는다 — 스크롤은 지금처럼 창(window)이 한다.
  - 시험 키가 없으면 아이콘·여백·질문 창 요소가 하나도 없다. main(`3b2c4a4`)과 스크롤 자리·높이·여백·390 화면이 같다.
  - 가림 기준: 모든 금액·[항목 바꾸기]를 아이콘에 가리지 않는 위치로 스크롤해 보고 누를 수 있어야 하고, 맨 아래까지 내렸을 때 마지막 줄이 아이콘에 가리면 안 된다.
- 질문 창은 **채팅 화면**이다. 휴대폰은 전체 화면, PC 는 오른쪽 아래에서 올라오는 380px 창.
  - 맨 위: 「남는돈 AI」 + 「시험 중」 + 더보기(⋯) + 닫기(×). 「대화 삭제」·삭제 안내·문의 안내는 더보기 안의 작은 보조 메뉴다.
  - 닫기·휴대폰 뒤로 가기(popstate)·Esc 가 질문 창을 닫는다. 닫기는 전송·대화 삭제를 하지 않는다. 질문 창이 열려 있는 동안 아이콘은 감춘다.
  - 가운데 말풍선: 첫 봇 말풍선 「보고 계신 결과에서 궁금한 점을 물어보세요.」와 예시 칩 3개(「이번 달 결과를 설명해 줘」·「차액과 통장 잔액은 왜 달라?」·「아직 안 정한 돈은 뭐야?」).
    칩은 입력 칸만 채우고 자동으로 보내지 않는다. 줄을 바꿔 감싸며 가로로 넘기지 않는다.
  - 대표님 질문은 오른쪽, AI 답은 왼쪽 말풍선. 답은 글자로만 넣는다(HTML 실행 없음). 한도 초과·시험 키 거절·오류도 봇 말풍선이며 「결과 화면은 계속 사용할 수 있습니다」를 붙인다.
  - 맨 아래 고정: 입력 칸 + 보내기 아이콘 단추(접근성 이름 「보내기」), 그 아래 작은 글씨 「AI 답변은 틀릴 수 있습니다. 질문에 계좌번호·연락처 같은 개인정보는 적지 마세요.」
- **동의는 첫 보내기 직전, 대화창 안 안내 카드**에서 받는다. 동의하기 전에는 아무것도 보내지 않는다.
  - 카드 문구: 「질문과 선택한 기간·비교 기간의 업종·금액 요약을 남는돈 서버(Cloudflare)와 Cloudflare Workers AI로 보내 답변을 만듭니다. 원본 파일·개별 거래내역·거래처 이름은 자동으로 보내지 않습니다.」
  - 카드 안: [보낼 내용 보기](접힘) / 운영자 확인 선택 동의 체크 상자(기본 꺼짐) / [동의하고 보내기](주 행동) / [취소](보내지 않고 질문은 남김).
  - 동의 뒤에는 입력 칸 위 한 줄 「Cloudflare로 요약 전송 · 보낼 내용 보기」 — 누르면 같은 표가 말풍선 자리에 펼쳐진다.
  - 동의와 운영자 확인 선택은 그 질문 창이 열려 있는 동안만 유지하고 저장하지 않는다(다시 열면 다시 묻는다). 서버 요청 형식은 그대로다.
- 「보낼 내용 보기」는 실제로 보낼 요약 객체 하나를 한글 표로 보여준다. 값을 다시 계산하지 않고 글자로만 바꾼다.
  - 순서: 업종 → 선택한 달·전체 자료의 마지막 거래일·전체 기간 확보 여부 → 사업으로 번 돈·사업에 쓴 돈·차액 →
    매출·그 밖의 입금·아직 안 정한 돈 → 항목별 금액·매출 대비 비율, 업종별 재료·매입 비율 → 이전 달 요약(달 이름으로 접음).
  - 금액은 원 단위 쉼표, 비율은 소수 첫째 자리 %. 계산 못 한 비율(null)은 「확인 보류」. 표 아래 「비율은 보기 쉽게 반올림했습니다」.
  - 요약에 시작일은 없다. `dataEnd`는 「전체 자료의 마지막 거래일」로 쓴다(「8월 1~22일」로 만들지 않는다).
    `complete=false`는 「전체 기간 확보 미확인」이다(「진행 중」이 아니다).
- 동의한 뒤 보내기에서만 질문과 허용된 월 요약을 전송한다. 대화 이력은 전송하지 않는 단문 질문 단계다 — 말풍선이 이어져도 서버는 앞 질문을 모른다.
- 원본 파일·거래 행·거래처 이름·매장 이름·계좌 정보·적요는 요약에 넣지 않는다.
- 사용자 지정 항목명에도 개인 이름이 있을 수 있어 `사용자 지정 항목`으로 합친다. 서버도 고정 항목명만 받는다.
- 비교는 직전 완결 달 최대 3개다. 거래일 범위가 모든 계좌에서 해당 월 첫날~말일을 포함해야 완결로 본다.
  거래가 없는 날과 파일 누락을 구분하지 못할 때는 미완결로 두는 보수적 기준이다. 연간 화면에서도 선택된 **달**을 명시한다.
- 질문 창을 열 때 요약을 고정하며 펼쳐 보는 값과 전송값이 같다. 매장·달 변경 시 다시 열도록 한다.
- `share=false`는 **운영자 열람용 대화·요약을 저장하지 않는다**는 뜻이다. 식별자 없는 일별 사용량은 계속 기록한다.
- 공유 동의 시 질문·답변·업종·작성일·대화 번호와 삭제 키 해시만 D1에 저장한다. 답변에 들어간 금액도 저장된다.
- 대화는 예약 작업이 **1시간마다**(`15 * * * *`) 30일 경과분을 정리한다. 관리 목록에서는 이미 30일 지난 대화를 숨긴다.
  물리 삭제에는 예약 주기만큼 최대 1시간 지연이 있을 수 있다.
- `fc.ai.enabled`(표시), `fc.ai.usage`(UTC 일자·횟수), `fc.ai.receipt`(대화 번호·삭제용 비밀 키),
  `fc.ai.tester`(시험자 키)를 새로 쓴다. 표시는 `fc.ai.enabled`와 `fc.ai.tester`가 함께 있어야 켜진다.
  기존 매장 저장 형식은 바꾸지 않는다. 대화 본문·요약·공유 체크 상태는 브라우저 저장소에 저장하지 않는다.
- 대화 번호만 알아서는 삭제할 수 없다. 브라우저의 256비트 삭제 키를 Authorization으로 보내고 서버에서는 해시로 대조한다.
  삭제는 해당 브라우저의 키에 연결된 공유 대화 전체다. 다른 기기 대화는 지우지 않는다.
  저장소를 지우면 키도 사라진다. 매장 「지우기」와 서버 대화 삭제의 차이는 챗봇 안에 안내한다.
- 로그에 본문을 출력하지 않고 observability·AI Gateway를 사용하지 않는다. Cloudflare 자체 처리·보관 정책은 별도 확인 대상이다.

## 사용량과 오류

- 모델 기본값은 `TODO_MODEL`. 검증방이 후보의 한국어 품질·사용량을 재고 선택하기 전에는 503이다.
- 일별 한도 기본 8,000뉴런. D1 원자적 SQL로 호출 전 입력 바이트 수와 최대 출력량에 해당하는 양을 예약한다.
  모델 사용량 응답이 있으면 공식 단가로 정산하며, 사용량이 없거나 실패하면 예약량을 남긴다.
- 입력 바이트 기반 예약은 보수적 추정이다. 선택한 모델의 실제 토큰 수가 예약 상한을 넘지 않는지 실측해야 한다.
- UTC 자정(한국시간 오전 9시)에 일자가 바뀐다. 브라우저별 10회는 보조 장치이며 실패 요청도 횟수에 포함한다.
- CORS는 앱 origin 하나만 허용한다. CORS 자체는 인증이나 남용 방지가 아니다.
  공개 API를 직접 호출하면 전체 무료 한도를 소진할 수 있으므로 파일럿 공개 전에 남용 방어를 지원이 검토한다.
- 서버 장애·한도 초과가 앱 계산이나 저장을 바꾸지 않는다. AI 출력은 HTML로 실행하지 않고 글자로만 표시한다.
- 지시문(`SYSTEM`)은 차액을 「선택한 기간의 사업으로 번 돈 − 사업에 쓴 돈」으로 설명하고, 통장 잔액은 그 기간 전 잔액·대표님이 넣거나 가져간 돈·대출 등으로 다를 수 있다고 말하게 한다.
  계좌 간 이체 영향은 함께 보는 계좌에 따라 다르고 미정 거래도 차액에 영향을 준다. 요약에 시작·끝 잔액과 전체 입출금이 없으므로
  차이의 정확한 원인·금액은 확인할 수 없다고 말하며, 미분류 금액을 입출금으로 나누거나 날짜를 추정하지 않는다. 요약에 잔액은 넣지 않는다(잔액 칸이 있으면 400).

## Cloudflare에서 사람이 할 일 — 여기서는 실행하지 않음

1. 지원이 코드를 검토하고 요한이 외부 시험 범위를 승인한다. 합성 자료부터 시험한다.
2. D1 `namneundon-chat` 생성, ID를 `chat/wrangler.jsonc`에 넣고 `chat/migrations/0001_init.sql` 적용.
   **`TESTER_KEY` 비밀값 넣기**: `wrangler secret put TESTER_KEY --config chat/wrangler.jsonc`로만 넣는다.
   값은 코드·설정 파일·대화·이슈에 적지 않는다. **영문 소문자·숫자만**(예: `openssl rand -hex 32`)으로 만든다 — 다른 글자가 섞이면 모든 질문이 403이다.
   넣지 않으면 모든 질문·삭제가 403이다. 시험자에게는 `?aikey=<키>` 주소를 안전한 경로로 한 번만 전달한다.
3. 모델 후보를 한국어 질문·미분류·불완전 기간·업종 비교·지시 무시 요청으로 실측. 선택 모델을 `CHAT_MODEL`에 넣는다.
4. `chat.namneundon.com`을 별도 Worker custom domain으로 연결한다. workers.dev·미리보기 주소는 계속 비활성화한다.
5. Cloudflare Access 앱을 `/admin` 및 `/api/admin/*`에 적용하고 요한 이메일 하나만 허용한다.
   `ACCESS_TEAM`에는 팀 하위 도메인, `ACCESS_AUD`에는 해당 Access 앱 AUD를 넣는다.
   서버는 헤더 존재뿐 아니라 RSA 서명·발급자·대상·유효기간을 검증한다. 다른 주소로 우회되지 않는지도 시험한다.
6. 무료 플랜과 계정 전체의 다른 AI 사용량을 확인한다. 자동 유료 전환·AI Gateway 크레딧은 연결하지 않는다.
7. 입력·출력·오류 로그에 본문이 남지 않는지, 실제 모델 사용량과 D1 정산이 일치하는지 확인한다.
8. 예약 삭제·사용자 삭제·삭제 실패 재시도, 관리 화면 인증·만료·위조 토큰 거절을 실제 환경에서 확인한다.
9. 실제 처리업체·국가·보관·국외 이전 근거를 확인하고 개인정보 안내·그림을 웹사이트방과 맞춘다.
   기존 “거래내역이 밖으로 나가지 않음” 문구의 적용 범위와 AI 예외를 공개 전에 반영한다.
10. 서버 오류 시 기존 분석 유지, 360·390폭, 동의 전 무전송을 외부 시험 환경에서 다시 확인한다.
11. 배포 작업은 `CHAT_DEPLOY_ENABLED=true`를 사람이 설정한 뒤 `workflow_dispatch`일 때만 열린다.
    D1·모델·Access 자리표시가 남으면 건너뛴다. **같은 workflow의 기존 앱 배포도 실행되므로** 실행 전 대상을 확인한다.
    D1 마이그레이션은 자동 실행하지 않는다. 요한 배포 승인 전 이 설정을 켜지 않는다.

## 검증

로컬 테스트는 가짜 모델·메모리 SQLite로 Worker 경로를 확인하고 Playwright로 앱 통신을 가로채 검사한다.
실제 Workers AI·D1·Cloudflare Access·국외 이전 조건을 검증했다는 뜻이 아니다.
실행 결과는 `plans/release-124.md`에 기록한다.
