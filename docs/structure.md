# 앱 파일 구조 (리팩토링 2단계 기준)

`app/` 폴더가 그대로 배포된다. 빌드 단계는 없다.

```
app/
├─ index.html            뼈대 + CSS·JS 불러오기 (205줄)
├─ css/app.css           화면 모양 전부
├─ src/                  JavaScript. 번호 순서대로 불러온다
├─ xlsx.full.min.js      엑셀 읽기 도구 (필요할 때만 불러옴)
├─ pdf.min.js · pdf.worker.min.js   PDF 읽기 도구 (필요할 때만)
├─ _headers              Cloudflare 캐시 규칙
├─ manifest.json · sw.js · icon-*.png   홈 화면 설치(PWA)
└─ robots.txt            검색 노출 차단
```

## 지켜야 할 것

- **파일 순서가 곧 실행 순서다.** `index.html`의 `<script>` 순서를 바꾸지 않는다.
- 모든 함수와 변수는 아직 전역이다 (한 파일이었을 때와 같다). 모듈로 나누는 것은 3단계.
- 앞 파일이 불러오는 순간 뒤 파일의 이름을 쓰면 깨진다. 원래 한 파일일 때는 괜찮았던 일이다.
  `npm run check` (`tools/check-load-order.mjs`)가 이것을 찾는다. `npm test` 와 CI 에서 먼저 돈다.
