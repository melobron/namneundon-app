## 배경

main 에 합치면 곧바로 운영에 배포된다. GitHub 의 브랜치 보호 규칙은 비공개 저장소 무료 요금제에서 적용되지 않는다.

## 결정

- GitHub Pro 를 쓰지 않는다.
- 「main 에 직접 push 하지 않고 PR 로만, CI 가 통과한 뒤 합친다」를 **약속**으로 지킨다. AI 도 같다.

- GitHub Pro(유료)로 보호 규칙 켜기.
- 저장소를 공개로 — 사업 코드라 하지 않는다.

## 결과와 영향

- 실수로 main 에 push 하는 것을 기계가 막아 주지 않는다. AGENTS.md · README 에 규칙으로 적는다.
- 커밋 전 검사(husky)와 CI 가 안전망이다.
