# 0001 · 서버 없이 브라우저 안에서만 계산 · 저장한다

- 상태: **확정**
- 정한 때: 이 저장소 이전부터 (119차 앱 시절). 2026-09-25 AGENTS.md 에 규칙으로 적혔다
- 정한 사람: 운영자(대표)

## 배경

거래내역은 계좌 · 거래처 · 금액이 모두 드러나는 민감한 자료다. 소상공인 대표가 처음 보는 앱에 이 파일을 올리려면
「밖으로 나가지 않는다」는 확신이 필요하다.

## 결정

- 앱은 정적 파일뿐이고 서버 코드가 없다. 파일 읽기 · 계산 · 저장을 모두 사용자 브라우저 안에서 한다.
- 거래내역을 네트워크로 보내는 코드를 만들지 않는다. 시작 화면에 「파일은 서버로 전송되지 않습니다」라고 약속한다.
- 저장은 그 브라우저의 `localStorage` 에만 한다.

## 대안

- 서버에 올려 계산 · 저장 — 여러 기기 동기화가 되지만 약속이 깨지고, 개인정보 보관 책임이 생긴다.

## 결과와 영향

- 서버 비용 · 계정 · 보안 사고 위험이 거의 없다.
- 자료가 한 브라우저에만 있다. 기기를 바꾸거나 앱 주소가 바뀌면 자료가 안 따라간다 ([deployment](../development/deployment.md#주소를-바꿀-때--사용자-자료)).
- 외부 서비스(맞춤법 검사기 등)에 글을 보내는 도구도 쓰지 않는다 ([quality](../development/quality.md)).
- 서버 동기화는 앞으로의 선택지로만 남아 있다 (정해지지 않음, [backlog](../backlog.md) B-2).
