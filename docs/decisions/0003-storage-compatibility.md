# 0003 · 저장 자료의 이름 · 형식을 바꾸지 않는다

- 상태: **확정**
- 정한 때: 앱 회차 기록(36차 · 91차 등)에서 이어져 온 원칙. 2026-09-25 AGENTS.md 「절대 하지 않는 것」 1번
- 정한 사람: 운영자

## 배경

사용자가 정한 거래처 분류는 브라우저 `localStorage` 에만 있다. 저장 이름(key)이나 형식을 바꾸면 새 코드가 옛 자료를 못 읽고,
사용자는 수십 곳을 처음부터 다시 정해야 한다. 되살림이 「조용히 0곳」이 되는 사고가 여러 회차에 있었다 (38차 · 46차 · 63차 주석).

## 결정

- `fc.picks.*` · `fc.manual.*` · `fc.banks.*` · `fc.data.*` · `fc.plan.*` · `nd_lastrun.*` · `fc.breaks` · `fc_use` 등 저장 이름과 형식을 바꾸지 않는다 (목록: [domain-rules](../product/domain-rules.md#저장-자료)).
- 꼭 바꿔야 하면 사용자와 먼저 정하고, **옛 자료를 읽어 새 형식으로 옮기는 코드**를 함께 쓴다. 판 번호(`cv` · `v` · `dv`)로 구분한다.
- `fc.picks` 에 금액을 담지 않는 검사(`hasNumber`)를 풀지 않는다. 금액이 필요하면 통을 따로 만든다.

## 대안

- 형식을 자유롭게 바꾸고 사용자에게 다시 정하게 하기 — 실사용자가 생긴 뒤에는 받아들일 수 없다.

## 결과와 영향

- 저장 형식이 조금씩 누적된다 (옛 판 읽기 코드가 남는다).
- `tests/upload.spec.mjs` 가 저장 자료 스냅샷(`storage.json`)과 「되살린 숫자 = 저장 전 숫자」를 지킨다.
- PR 템플릿에 확인 칸이 있다.
