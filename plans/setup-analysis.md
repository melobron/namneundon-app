## 요구사항과 구현 방법

인터넷이 열려 있을 때 `npm run setup` 하나로 웹·Python 분석 환경을 준비하고,
차단 뒤 앱·소개 사이트·분석 CLI·노트북을 로컬에서 사용한다.
Windows에 호환 Python이 없으면 공식 설치 파일의 해시를 검증해 사용자 계정에 설치한다.
기존 v3 분석 코드와 기본 설정을 재사용하며 실제 자료·설정·결과를 재실행으로 덮어쓰지 않는다.
대용량 사전 배포 ZIP·별도 Windows 실행 파일은 만들지 않는다.

프로젝트 `.venv`와 고정 의존성을 쓰고 doctor·웹 전용 옵션을 유지한다.
설치 시 `init`·`freeze`·`demo`를 실행하지 않는다. 분석 명령은 가상 환경 활성화 없이 npm으로 실행한다.
실제 자료 없이 Excel·Parquet, 통계·그래프, 커널·Jupyter 응답을 검사한다.

## 이전 검증 기록

아래는 기존 tasks 문서의 보고를 옮긴 것이며 이번 문서 정리에서 다시 실행하지 않았다.
