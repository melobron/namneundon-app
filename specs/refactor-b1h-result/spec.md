## 문제와 목적

결과 화면(`15-result-panels.js` · `17-result.js`)과 1년치 그래프(`18-charts-year.js`)에 화면 · 저장소에 닿지 않는 계산이 섞여 있다 — 볼 달 고르기, 달 이름, 그래프 눈금, 하루 흐름, 문 열기 전 달, 사업 외 목록 같은 것.
B-1a~g 와 같은 방식으로 `core/` 로 옮겨 화면 없이 돌고 시험할 수 있게 한다.

## 요구사항

- **R1.** 세 파일의 순수 계산(`npm run purity -- --up` 기준)을 `app/src/core/result.js` 로 옮긴다.
- **R2.** 매장 자료(`UP`)를 읽는 함수는 `fIn(U, …)` 로 옮기고, 원래 자리에 같은 이름의 연결 함수를 남긴다.
- **R3.** 옮긴 계산이 Node 와 브라우저에서 같은 답을 내는지 시험한다.
- **R4.** 분석 도구가 「매개변수로 받은 화면 요소를 다루는 함수」를 순수로 잘못 치지 않게 한다 (이번에 `moneyLive(inp)` · `drawDueAsk2(days)` 가 그렇게 잡혔다).

## 범위

- 포함: 위 세 파일의 순수 계산과 그것이 쓰는 상수(`12` 의 `CASH_NAME` 포함), `tools/analyze-purity.mjs` 판정 보강.
- **제외**: 화면 · 저장소 코드, 펼침 상태(`whyOpen` · `whyKey`), 동작 변경. 저장 자료 이름 · 형식, 화면 글자 · 계산 숫자는 바뀌지 않는다.
