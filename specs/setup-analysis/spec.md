# 기존 초기 설정에 분석 환경 포함

상태: Implementing

2026-09-28 사용자가 1단계 머지 후 2·3단계를 순차 구현하고 이상 없으면 머지하도록 지시했다.

## 요구사항

- 인터넷 연결 중 `npm run setup` 하나로 웹과 Python 분석 환경을 준비한다.
- Windows 에 호환 Python 이 없으면 공식 설치 파일을 검증하고 사용자 계정에 설치한다.
- 인터넷 차단 뒤 앱·소개 사이트·분석 도구·노트북을 로컬에서 사용한다.
- 원본 분석 코드를 재사용하며 실제 데이터와 설치 결과를 GitHub 에 올리지 않는다.
- 재실행 시 실제 자료·기존 분석 설정·결과를 덮어쓰지 않는다.
- 대용량 사전 배포 ZIP 과 별도 Windows 실행 파일을 만들지 않는다.
