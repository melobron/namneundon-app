## 문제와 목적

`13-onboard.js`(거래처를 차례로 묻는 화면)에는 화면 · 저장소에 닿지 않는 계산이 섞여 있다. 사람 이름 가리기, 개인 · 대출 짐작, 묶음, 묻는 차례, 목표선 같은 것이다.
이것들이 화면 코드 안에 있어서 Node 에서 단위 테스트를 할 수 없다. B-1a~f 와 같은 방식으로 `core/` 로 옮겨 화면 없이 돌고 시험할 수 있게 한다.

## 요구사항

- **R1.** `13-onboard.js` 의 순수 계산(분석 도구 `npm run purity -- --up` 기준)을 `app/src/core/onboard.js` 로 옮긴다.
- **R2.** 매장 자료(`UP`)를 읽는 함수는 `fIn(U, …)` 로 옮기고, 원래 자리에 같은 이름의 연결 함수 `f(…)` 를 남긴다 — 앱의 다른 코드는 바뀌지 않는다.
- **R3.** 옮긴 계산이 Node 와 브라우저에서 같은 답을 내는지 시험한다.

## 범위

- 포함: `13-onboard.js` 의 순수 계산과 그것이 쓰는 상수(`06` 의 `BOOKKEEPING_WORDS`, `07` 의 `UP_TARGET` 포함).
- **제외**: 화면 · 저장소 코드, 동작 변경. 저장 자료(`localStorage`) 이름 · 형식, 화면 글자 · 계산 숫자는 바뀌지 않는다.

## 사용 시나리오

해당 없음 (사용자에게 보이는 변화 없음).

## 경계 조건

- 연결 함수가 없는 사이에 앱 코드가 옛 이름을 부르면 깨진다 → 같은 이름의 연결 함수를 남기고 `npm run check` 로 확인한다.
- 상수를 다른 파일로 옮기면 불러오는 순서가 바뀐다 → `core/` 는 앱 코드보다 먼저 불러오므로 앞당겨질 뿐이다.
