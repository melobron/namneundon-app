## 문제와 목적

B-1a~h 뒤에도 `02` · `07` · `10` · `11` · `12` 에 화면 · 저장소에 닿지 않는 계산이 남아 있다 — 조사 붙이기, 항목 이름 찾기, 파일 판별, 못 읽은 까닭 글, 저장 자료 모양 검사.
이것을 옮기면 B-1(계산 핵심 분리)이 끝난다 — 앱 파일에 남는 순수 함수는 core 를 부르는 연결 함수뿐이 된다.

## 요구사항

- **R1.** 남은 순수 계산을 주제별 core 파일 넷으로 옮긴다: `text.js`(조사 · HTML 막기) · `categories.js`(항목 이름) · `files.js`(파일 판별 · 까닭 글) · `saved.js`(저장 자료 모양 검사 · 옛 판 옮기기).
- **R2.** 매장 자료(`UP`)를 읽는 함수는 `fIn(U, …)` 로 옮기고, 원래 자리에 같은 이름의 연결 함수를 남긴다.
- **R3.** 옮긴 계산을 시험한다 — UP 를 읽는 것은 Node = 브라우저 교차 시험, 나머지는 단위 시험.

## 범위

- 포함: 위 다섯 파일의 순수 계산과 그것이 쓰는 상수.
- **제외**: `demoRows`(예시 거래 자료와 묶여 있고 테스트 불러오기가 앱 파일에서 집어 온다), 화면 · 저장소 코드, 동작 변경.
  **저장 이름(key) · 형식은 바뀌지 않는다** — `saved.js` 로 오는 것은 검사 · 옮기기 계산뿐이고, 읽고 쓰기는 `00-storage` · `12-storage` 에 그대로 있다.
