# VDI 오프라인 실행 환경

- 상태: Draft
- 작성일: 2026-09-28
- 기준: main `302ea60`
- 요청: 인터넷 개방 종료 전에 GitHub 에 실행에 필요한 자료를 준비하고 Windows VDI 에서 몇 개 명령으로 로컬 웹사이트·개발·분석을 사용한다.

## 범위

앱과 소개 사이트의 로컬 실행, Windows 런타임·개발 의존성·테스트 브라우저, 분석도구 v3 와 Python 을 준비한다. 운영 파일·계산·저장 규칙은 변경하지 않는다. 사용자 요청에 따라 구현과 검증을 진행하며 이 문서의 승인 상태는 임의로 바꾸지 않는다.

## 완료 기준

- 준비된 Windows 묶음을 GitHub 에서 다운로드할 수 있다.
- 압축 해제 뒤 명령으로 앱·소개 사이트를 실행한다. 소개 사이트의 시작 링크는 로컬 앱을 연다.
- 외부 요청 차단 상태에서 예시 계산과 소개 화면 검증을 통과한다.
- npm 캐시만으로 의존성 복원이 되고 Windows 전체 테스트·린트를 통과한다.
- 분석도구 자체 검사를 통과하며 실제 평가용 초기화·동결은 실행하지 않는다.
- 실제 VDI 의 실행 여부와 GitHub Windows 의 검증 결과를 구분한다.

온라인 AI·배포·외부 상담 서비스, Git·편집기 설치는 포함하지 않는다. 앱에 거래자료 전송 기능을 추가하지 않는다.
